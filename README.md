# Opprinnelig prompt

Jeg ønsker å lage en applikasjon der man kan skrive inn et navn eller et organisasjonsnummer også får man opp informasjon om bedriften

# Selskapsinnsikt

Søk etter norske virksomheter med navn eller organisasjonsnummer. Appen viser offentlig informasjon fra [Enhetsregisteret hos Brønnøysundregistrene](https://data.brreg.no/enhetsregisteret/api/).

## Kom i gang

```bash
npm install
npm run dev
```

Åpne adressen Vite viser i terminalen. Bygg produksjonsversjonen med `npm run build`.

Appen kaller Brønnøysundregistrenes åpne API direkte fra nettleseren og trenger ingen API-nøkkel eller egen server.
