# Agentisk utvikling — presentasjon

En terminalpresentasjon laget med [OpenTUI](https://opentui.com/docs/components/ascii-font/).

Krever [Bun](https://bun.sh/) 1.3 eller nyere. Kjør fra denne mappen:

```sh
bun install
bun run start
```

Bruk en terminal på minst 80 kolonner og 24 rader for tittelsliden. `→` eller
`Space` går til neste slide; `←` går til forrige. Slide 2 viser «Curious, Not
Converted» med bildet fra den tidligere LLM-presentasjonen.

`A` åpner akvariet og `S` åpner romskipet fra hvilken som helst slide, uten å
endre plass i presentasjonen. Trykk samme tast igjen eller `Esc` for å komme
tilbake, eller bytt direkte mellom pauseskjermene med `A` og `S`.

På pauseskjermene: `P` spiller/pauser animasjonen, `T` lar deg angi minutter og
starter nedtellingen med `Enter`, og `R` nullstiller nedtellingen. `Q` eller
`Ctrl+C` avslutter.

OpenTUIs innebygde ASCII-fonter mangler `Ø`, så den bokstaven i «første» er tegnet separat.
